J.A.R.V.I.S. v0.1.43 - UNIFIED CHAT LAYOUT + IMAGE FOLLOW-UP FIX

Prerequisite: current JARVIS frontend/backend version must be 0.1.42.

1. Stop both JARVIS terminal windows with Ctrl+C.
2. Save this ZIP to F:\JARVIS\patches\JARVIS_v0.1.43_Unified_Chat_Layout_Image_Followup_Fix.zip.
3. Open Windows PowerShell 5.1 (any working directory) and run:

New-Item -ItemType Directory -Force 'F:\JARVIS\patches\v0.1.43' | Out-Null
Expand-Archive -LiteralPath 'F:\JARVIS\patches\JARVIS_v0.1.43_Unified_Chat_Layout_Image_Followup_Fix.zip' -DestinationPath 'F:\JARVIS\patches\v0.1.43' -Force
Set-ExecutionPolicy -Scope Process -ExecutionPolicy Bypass -Force
& 'F:\JARVIS\patches\v0.1.43\Apply-JARVIS-v0.1.43.ps1'

4. Verify from PowerShell in F:\JARVIS\frontend:

npm run test:image-intent
npm run test:layout
npm run build

5. Restart JARVIS from F:\JARVIS with .\scripts\Start-JARVIS.ps1.

The installer makes a timestamped backup in F:\JARVIS\backups and rolls back if file verification fails.
It does not download anything and does not replace models, databases, generated images, imports, Python environments, or node_modules.

The UI now uses one left systems rail and one primary workspace. Assistant takes all remaining desktop width. On narrow displays, system navigation becomes a horizontal strip and the main workspace becomes full-width. The 3D intelligence view remains selectable from the same navigation.

Image routing now recognizes compound cutout/puppet diagram prompts and converts preceding text/ASCII guides into direct local SDXL image jobs. The trailing "svg" hint is treated as a vector-style prompt hint; ordinary SDXL output remains a PNG. Editable SVG output is currently generated by the existing precise-typography poster renderer, not by ordinary SDXL image generation.
