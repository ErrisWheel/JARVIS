J.A.R.V.I.S. v0.1.23 — Poster Refinement and Design Engine Fix

Install:
1. Stop both running JARVIS terminals (Ctrl+C).
2. Save this ZIP to F:\JARVIS\patches\JARVIS_v0.1.23_Poster_Refinement_Design_Engine_Fix.zip.
3. In PowerShell 5.1, use F:\JARVIS\patches as the working directory.
4. Extract to F:\JARVIS\patches\v0.1.23.
5. Run:

   Set-ExecutionPolicy -Scope Process -ExecutionPolicy Bypass -Force
   & '.\v0.1.23\Apply-JARVIS-v0.1.23.ps1'

The installer backs up replaced files under F:\JARVIS\backups. No models or dependencies are downloaded.

See JARVIS\docs\INSTALL-v0.1.23.md for verification and restart commands.
