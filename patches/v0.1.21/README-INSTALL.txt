J.A.R.V.I.S. v0.1.21 — Long-Form Poster Routing Recovery

This overlay fixes the exact failure where a long educational-poster brief fell through to normal chat. It also provides editable SVG output alongside the PNG preview.

Install: Stop both JARVIS terminals, extract the ZIP, then run Apply-JARVIS-v0.1.21.ps1 in PowerShell 5.1. The installer backs up all replaced files under F:\JARVIS\backups.

No models, runtimes or dependencies are downloaded.
